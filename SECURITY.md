# Security Policy

## Supported Versions

The latest version of TruthLens AI is actively maintained.

## Reporting a Vulnerability

If you discover a security issue, please avoid creating a public issue.

Instead, contact the repository owner with:

- Description of the issue
- Steps to reproduce
- Possible impact
- Suggested fix (if available)

Security reports will be reviewed as soon as possible.

Thank you for helping keep TruthLens AI secure.
